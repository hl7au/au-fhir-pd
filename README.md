# AU Provider Directory FHIR Implementation Guide

The [AU Provider Directory Implementation Guide](http://build.fhir.org/ig/hl7au/au-fhir-pd/) provides guidance on the implementation of provider directories using HL7<sup>&reg;</sup> FHIR<sup>&reg;&copy;</sup> in an Australian usage context.

This guide defines the profiles, extensions, terminology, and search parameters needed to represent and exchange provider directory information, including:
- Practitioners
- Practitioner roles
- Organisations
- Locations
- Healthcare services
- Endpoints

Profiles defined by this guide include:
- AU PD Practitioner
- AU PD Practitioner Role
- AU PD Organisation
- AU PD Location
- AU PD Secure Messaging Endpoint
- AU PD Healthcare Service

For a detailed description of these profiles and how they should be used, see the [Profiles and Extensions](http://build.fhir.org/ig/hl7au/au-fhir-pd/profiles.html)

## Contributing to AU Provider Directory Development

### 1. Join the AU Provider Directory Work Group

Email fhirwglist@hl7.com.au to join the HL7 AU FHIR working group. Visit the [HL7 Australia FHIR Work Group Home](https://confluence.hl7.org/display/HAFWG/HL7+Australia+FHIR+Work+Group+Home).

### 2. Discuss an issue in chat.fhir.org

If you have a question, feature request, or proposed change, the best place to start is Zulip e.g. the https://chat.fhir.org/#narrow/stream/179166-implementers stream. If what you want to discuss is specific to Australia you can post in the Australia stream https://chat.fhir.org/#narrow/channel/179173-australia/topic/AU.20Provider.20Directory/with/627635205.

### 3. Log an issue in Jira

Search the Issues list in [Jira issue tracker](xxx) to ensure the error was not already reported.

If you're unable to find an open bug addressing the problem, please create a bug report or issue in this project. You can use the ![Propose-a-change](https://github.com/hl7au/au-fhir-core/assets/116611317/642b45cb-c82e-4fb5-a24c-37b263289fac)
 option at the bottom of each page of the IG to trigger the creation of a Jira issue.

### 4. Discuss with the team

Once the issue is logged, you should discuss with the team on [chat.fhir.org in the australia stream](https://chat.fhir.org/#narrow/channel/179173-australia/topic/AU.20Provider.20Directory/with/627635205) before attempting to make changes yourself. It's important to coordinate with the other people working on the project.

### 5. Create a pull request

When everyone has agreed on a course of action, IG changes should be submitted as a pull request for review in this repository.
